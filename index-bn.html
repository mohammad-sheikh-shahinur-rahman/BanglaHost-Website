A to Z ফিচারসমূহ

BanglaHost এর ভেতরে লুকানো রয়েছে অসংখ্য শক্তিশালী ফিচার। নিচে সবগুলো ফিচারের একটি পূর্ণাঙ্গ তালিকা দেওয়া হলো:

সার্ভার ও রানটাইম

  • Multiple PHP Versions: PHP 7.4 থেকে 8.6 পর্যন্ত যেকোনো ভার্সন এক ক্লিকে ডাউনলোড ও ব্যবহার।
  • Auto PHP Detection: WordPress বা Laravel প্রজেক্ট ফোল্ডার সিলেক্ট করলেই সঠিক PHP ভার্সন অটো-ডিটেক্ট করা।
  • Nginx & Apache: হাই-পারফরম্যান্স ওয়েব সার্ভার সুইচিং।
  • Node.js & Python: Node.js অ্যাপস এবং Python প্রজেক্ট ম্যানেজমেন্ট।
  • PHP Extension Manager: UI থেকে সহজেই PHP এক্সটেনশন এনাবল/ডিজেবল করা।
  • php.ini Editor: প্রতিটি PHP ভার্সনের কনফিগারেশন সরাসরি এডিট করা।
  • Reverse Proxy: কাস্টম পোর্টের অ্যাপ্লিকেশনের জন্য রিভার্স প্রক্সি সেটআপ।
  • Docker Support: ডকার কন্টেইনার ম্যানেজমেন্ট ইন্টিগ্রেশন।

ডেটাবেস ও স্টোরেজ

  • Native SQL Studio: phpMyAdmin ছাড়াই বিল্ট-ইন নেটিভ অ্যাপ্লিকেশনে ডেটাবেস ম্যানেজ করুন।
  • Relational DBs: MySQL, MariaDB, PostgreSQL সাপোর্ট।
  • NoSQL DBs: MongoDB এবং SQLite সাপোর্ট।
  • In-Memory & Cache: Redis, Meilisearch এবং Cache Manager।
  • Backup & Restore: ১-ক্লিকে যেকোনো ডেটাবেস ব্যাকআপ (SQL dump) ও রিস্টোর করা।

ডেভেলপার পাওয়ার টুলস

  • Built-in Terminal: সঠিক এনভায়রনমেন্ট ভ্যারিয়েবলসহ ইন্টিগ্রেটেড PowerShell/CMD।
  • Local SSL: 1-Click Trusted SSL (HTTPS) জেনারেশন আপনার লোকাল সাইটের জন্য।
  • Auto Virtual Hosts: Hosts ফাইল অটো-ম্যানেজমেন্ট (যেকোনো .test ডোমেইন সেটআপ)।
  • API Tester: লোকালি API এন্ডপয়েন্ট টেস্ট করার জন্য বিল্ট-ইন টুল (Postman-এর মতো)।
  • Mailpit Inbox: লোকাল ইমেইল টেস্টিং এবং ডিবাগিং করার জন্য ইনবক্স।
  • Env Manager: প্রজেক্টের .env ফাইল ম্যানেজ করার ডেডিকেটেড টুল।
  • VS Code Integration: এক ক্লিকে প্রজেক্ট ফোল্ডার VS Code-এ ওপেন করার সুবিধা।
  • NPM & Package Manager: UI থেকে সরাসরি NPM স্ক্রিপ্ট রান করার সুবিধা।

অটোমেশন ও ডেভঅপস

  • Site Cloning & Blueprints: একটি সাইট ক্লোন করে নতুন স্টেজিং এনভায়রনমেন্ট তৈরি করা।
  • Cloudflare Tunnel: পোর্ট ফরওয়ার্ডিং ছাড়াই লোকাল সাইট ইন্টারনেটে লাইভ শেয়ার করা।
  • Cron & Scheduler: লোকালি যেকোনো স্ক্রিপ্ট নির্দিষ্ট সময়ে রান করার জন্য Cron Manager।
  • Queue Manager: ব্যাকগ্রাউন্ড জব এবং কিউ প্রসেসিং।
  • Git & GitHub Actions: লোকাল রিপোজিটরি ম্যানেজমেন্ট এবং গিট ইন্টিগ্রেশন।
  • Deploy Manager: লোকাল সাইট প্রোডাকশন সার্ভারে ডিপ্লয় করার টুলস।
  • File Watcher: প্রজেক্টের ফাইল চেঞ্জ রিয়েল-টাইমে মনিটর করার সিস্টেম।

মনিটরিং ও AI

  • Local AI Assistant (Ollama): প্রাইভেট লোকাল LLM মডেল ব্যবহার করে কোডিং অ্যাসিস্ট্যান্ট।
  • Performance Profiler: অ্যাপ্লিকেশনের স্পিড ও পারফরম্যান্স প্রোফাইলিং।
  • Site Health: সাইটের সিকিউরিটি এবং হেলথ চেকিং টুল।
  • System Tray Monitoring: ব্যাকগ্রাউন্ড সার্ভিস হিসেবে চলাকালীন CPU ও RAM মনিটরিং।
  • Network & Security: নেটওয়ার্ক কানেকশন এবং সিকিউরিটি অ্যানালাইজার।
  • Marketplace: অতিরিক্ত প্লাগিন ও এক্সটেনশন ইনস্টল করার স্টোর।

কী কী প্রয়োজন?

BanglaHost অত্যন্ত লাইটওয়েট এবং ফাস্ট। তবে সেরা পারফরম্যান্সের জন্য আপনার পিসিতে নিচের স্পেসিফিকেশন থাকা প্রয়োজন:

  • অপারেটিং সিস্টেম: Windows 10 (Version 1809 বা এর ওপর) অথবা Windows 11 (Recommended)
  • প্রসেসর (CPU): যেকোনো 64-bit (x64) ডুয়েল কোর প্রসেসর
  • র‍্যাম (RAM): কমপক্ষে 4GB (8GB রিকমেন্ডেড)
  • স্টোরেজ: অ্যাপের জন্য 500MB ফ্রি স্পেস (আপনার প্রোজেক্ট এবং ডাটাবেসের জন্য অতিরিক্ত স্পেস প্রয়োজন হবে)

Frequently Asked Questions

BanglaHost কি সম্পূর্ণ ফ্রি?

হ্যাঁ, BanglaHost সম্পূর্ণ ফ্রি এবং ওপেন সোর্স (Open Source)। আপনি কোনো সাবস্ক্রিপশন ছাড়াই এর সকল প্রিমিয়াম ফিচার ব্যবহার করতে পারবেন।

XAMPP বা Laragon এর সাথে এর পার্থক্য কী?

XAMPP বা Laragon এর তুলনায় BanglaHost অনেক বেশি আধুনিক (.NET 8 ও WinUI 3 দিয়ে তৈরি)। এতে Cloudflare Tunnel, AI Assistant, Mailpit, Native SQL Studio, Site Cloning এবং Auto SSL এর মতো এডভান্সড টুলস বিল্ট-ইন রয়েছে, যা অন্য কোথাও একসাথে পাওয়া যায় না।

আমি কি একসাথে একাধিক PHP ভার্সন ব্যবহার করতে পারবো?

হ্যাঁ! আপনি একেকটি সাইটের জন্য একেকটি PHP ভার্সন (যেমন- একটিতে PHP 7.4 এবং অন্যটিতে PHP 8.2) সিলেক্ট করতে পারবেন এবং সেগুলো কোনো কনফ্লিক্ট ছাড়াই একসাথে চলবে।

এটি কি WordPress এবং Laravel সাপোর্ট করে?

অবশ্যই। BanglaHost বিশেষভাবে WordPress এবং Laravel ডেভেলপারদের কথা মাথায় রেখে তৈরি করা হয়েছে। এতে 1-click install, WP-CLI, Composer এবং Auto PHP Detection এর সুবিধা রয়েছে।
