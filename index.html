DEEP DIVE

A to Z Capabilities

BanglaHost hides countless powerful features under the hood. Here is a comprehensive list of its capabilities:

Server & Runtime

  • Multiple PHP Versions: 1-click download and use any version from PHP 7.4 to 8.6.
  • Auto PHP Detection: Select a WordPress or Laravel folder and the correct PHP version is auto-detected.
  • Nginx & Apache: Switch between high-performance web servers seamlessly.
  • Node.js & Python: Full environment management for Node.js apps and Python projects.
  • PHP Extension Manager: Enable or disable PHP extensions directly from the UI.
  • php.ini Editor: Edit configurations for each PHP version independently.
  • Reverse Proxy: Setup reverse proxies for apps running on custom ports.
  • Docker Support: Integrated Docker container management.

Databases & Storage

  • Native SQL Studio: Manage databases with a built-in native app (no phpMyAdmin needed).
  • Relational DBs: Full support for MySQL, MariaDB, and PostgreSQL.
  • NoSQL DBs: MongoDB and SQLite support.
  • In-Memory & Cache: Redis, Meilisearch, and Cache Manager.
  • Backup & Restore: 1-click database backup (SQL dump) and restore.

Developer Tools

  • Built-in Terminal: Integrated PowerShell/CMD with correct environment variables injected.
  • Local SSL: 1-Click Trusted SSL (HTTPS) certificate generation for local sites.
  • Auto Virtual Hosts: Automated Hosts file management (setup any .test domain).
  • API Tester: Built-in tool for testing API endpoints locally (Postman alternative).
  • Mailpit Inbox: Local email testing and debugging sandbox.
  • Env Manager: Dedicated tool to manage project .env files.
  • VS Code Integration: Open project folders in VS Code with a single click.
  • NPM & Package Manager: Run NPM scripts directly from the UI.

Automation & DevOps

  • Site Cloning & Blueprints: Clone an existing site to instantly create a staging environment.
  • Cloudflare Tunnel: Share local sites live on the internet without port forwarding.
  • Cron & Scheduler: Cron Manager to run scripts locally on a specific schedule.
  • Queue Manager: Background job and queue processing.
  • Git & GitHub Actions: Local repository management and Git integration.
  • Deploy Manager: Tools to deploy local sites to production servers.
  • File Watcher: Monitor project file changes in real-time.

Monitoring & AI

  • Local AI Assistant (Ollama): Coding assistant using private local LLM models.
  • Performance Profiler: Application speed and performance profiling.
  • Site Health: Site security and health checking tools.
  • System Tray Monitoring: CPU & RAM monitoring while running as a background service.
  • Network & Security: Network connections and security analyzer.
  • Marketplace: Store to install additional plugins and extensions.

SYSTEM REQUIREMENTS

What do you need?

BanglaHost is extremely lightweight and fast. However, for the best performance, your PC should meet the following specifications:

  • Operating System: Windows 10 (Version 1809 or higher) or Windows 11 (Recommended)
  • Processor (CPU): Any 64-bit (x64) Dual-Core Processor
  • Memory (RAM): Minimum 4GB (8GB Recommended)
  • Storage: 500MB free space for the app (Additional space required for your projects and databases)
FAQ

Frequently Asked Questions

Is BanglaHost completely free?

Yes, BanglaHost is completely free and open-source. You can use all of its premium features without any subscriptions or hidden fees.

How is it different from XAMPP or Laragon?

Compared to XAMPP or Laragon, BanglaHost is much more modern (built with .NET 8 and WinUI 3). It includes advanced tools built-in, such as Cloudflare Tunnels, AI Assistant, Mailpit, Native SQL Studio, Site Cloning, and Auto SSL, which are not typically found together elsewhere.

Can I use multiple PHP versions simultaneously?

Yes! You can select a different PHP version for each site (e.g., PHP 7.4 for one site and PHP 8.2 for another) and they will run concurrently without any conflicts.

Does it support WordPress and Laravel?

Absolutely. BanglaHost is designed specifically with WordPress and Laravel developers in mind. It features 1-click installations, WP-CLI, Composer, and Auto PHP Detection to make development effortless.
